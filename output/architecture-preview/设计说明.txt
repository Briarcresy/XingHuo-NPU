设计依据
1. Gemmini: Enabling Systematic Deep-Learning Architecture Evaluation via Full-Stack Integration
   Fig. 1，PDF 第 1 页；已下载并实际查看。
   https://arxiv.org/pdf/1911.09925
   借鉴系统边界与计算核心分层、控制/存储/计算的分组方式。
2. In-Datacenter Performance Analysis of a Tensor Processing Unit
   Fig. 1，PDF 第 3 页；已下载并实际查看。
   https://arxiv.org/pdf/1704.04760.pdf
   https://research.google/pubs/in-datacenter-performance-analysis-of-a-tensor-processing-unit/
   借鉴功能配色、主数据通路、计算阵列内部结构的视觉强调。
3. Eyeriss: An Energy-Efficient Reconfigurable Accelerator for Deep Convolutional Neural Networks
   ISSCC 2016，Fig. 14.5.2，PDF 第 2 页（印刷页 263）。
   https://www.rle.mit.edu/eems/wp-content/uploads/2016/02/eyeriss_isscc_2016.pdf
   实际查看的是作者项目网站发布的高清架构图：
   https://eyeriss.mit.edu/images/architecture.png
   借鉴分开的操作数路径和重复 PE 的表达。

这里仅借鉴绘图方法；图中模块与连接均按本仓库 RTL 重新绘制。
没有引入参考架构中的 CPU、DMA、AXI、DDR 或大容量片上缓存。

读图说明
- (a) 是 XingHuoNpuTile 总览；(b) 展开的是 (a) 中同一个 XingHuo_NPU，非第二份硬件。
- 11 个基础功能框；其中 Core 在两级视图中重复表示。4 个 PE 为阵列内部图形。
- 一个内部时钟域。颜色区分功能类型，不代表不同的时钟域。
- 两层网络复用同一个 Core，H 为真实第一层输出。
- Shared RAM 位于 Tile 外部。仲裁器仅选择地址/写通路，读数据直接扇出。
- 显示/应答模块以文字注释概括，观察连线与握手返回信号省略。
- W00/W10 位于上排，W01/W11 位于下排；激活向下，部分和向右。
- Array 输出为两条 INT32 流；Collector 保存四个 INT32 结果。
- VPU 顺序为 Bias、算术右移、INT8 饱和、ReLU、结果寄存器。
- A/W/Bias/Shift 由 sequencer 保持；图中短入端箭头表明 W、Bias 和 Shift 的消费模块。
